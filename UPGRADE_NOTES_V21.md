# V21 — Live Class Archive + Institutional Welcome Signature

## Live classroom / revision workflow
- Teachers can schedule the next online class from the Live Classroom workspace using their actual class/subject assignments.
- Students in the selected class receive a notification when the class is scheduled.
- The school account remains the authentication boundary; the external video provider's pre-join/device/name screen is explicitly explained as a meeting-provider step, not a second school login.
- A completed class can be saved as a reusable learning resource with revision notes, an uploaded recording, or an external recording/resource link.
- Saving an archived class automatically notifies the selected class that the lesson is available for revision.
- Uploaded recordings can be downloaded through an authorization-checked route; external resources open through their supplied link.
- Saved classes can be published into the institutional Library with class and subject metadata, making them available for future revision.

## Welcome signature
- The public root portal now opens with a short institutional welcome animation before the landing page.
- The animation is intentionally sharp, serious and technology-oriented rather than dreamy: grid, accent rail, wordmark reveal, progress line and controlled fade into the portal.
- Admin / ICT can enable or disable it, edit the displayed company/platform name, and control the duration from the public landing branding controls.
- The default signature text is `Toror Technology and Innovations Ltd.`.
- The splash is shown on the public entry page, which is the destination used by the institution QR/root portal and public links.
